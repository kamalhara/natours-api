# Natours Backend API

A full-featured **RESTful backend API** for a tour booking application, built while coding along with *Jonas Schmedtmann’s Complete Node.js Bootcamp*.

This project focuses on **real-world backend development** including authentication, authorization, data modeling, and advanced API features using **Node.js, Express, and MongoDB**.

---

## 🚀 Features

### 🔐 Authentication & Authorization
- User signup & login
- JWT-based authentication
- Protected routes
- Role-based access control (admin, lead-guide, user)
- Password encryption using bcrypt
- Forgot & reset password flow

### 🧭 Tours API
- CRUD operations for tours
- Advanced filtering, sorting, pagination, and field limiting
- Aggregation pipelines (tour stats, monthly plans)
- GeoJSON-based location queries

### 👤 Users & Reviews
- User profile management
- Tour reviews & ratings
- Relationship modeling using Mongoose
- Middleware-based access control

### ⚙️ Backend Architecture
- MVC architecture
- Centralized error handling
- Async/await with global error catcher
- Environment-based configuration
- API versioning

---

## 🛠 Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB**
- **Mongoose**
- **JWT (JSON Web Tokens)**
- **bcrypt**
- **Nodemailer**
- **Postman** (API testing)
